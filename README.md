# 🐍 Quiz de Conhecimentos em Python

Projeto acadêmico desenvolvido em Python com o objetivo de criar um jogo de perguntas e respostas para praticar e demonstrar os conhecimentos adquiridos durante o curso.

## 🎯 Objetivo

Desenvolver um quiz interativo de múltipla escolha, no qual o jogador responde a perguntas relacionadas à linguagem Python, recebe feedback imediato sobre suas respostas e acompanha sua pontuação ao final da partida.

O projeto busca colocar em prática conceitos fundamentais de programação, desenvolvendo o raciocínio lógico e as habilidades de desenvolvimento.

## ⚙️ Funcionalidades

- Apresentação inicial com boas-vindas e instruções.
- Banco de perguntas com 10 questões sobre Python.
- Sorteio aleatório de 5 perguntas por partida.
- Quatro alternativas para cada pergunta (A, B, C e D).
- Validação das respostas digitadas pelo jogador.
- Indicação imediata de acerto ou erro.
- Contabilização automática da pontuação.
- Exibição do resultado final com acertos, erros e pontos obtidos.

## 🛠️ Tecnologias utilizadas

- **Python:** linguagem utilizada no desenvolvimento.
- **Rich:** biblioteca utilizada para melhorar a apresentação visual do terminal.
- **Random:** módulo utilizado para realizar o sorteio das perguntas.

## 📚 Conceitos de programação aplicados

- Listas e dicionários.
- Funções.
- Estruturas condicionais (`if` e `else`).
- Estruturas de repetição (`for` e `while`).
- Manipulação de dados.
- Validação de entradas.
- Importação de bibliotecas e módulos.

```bash

```

```bash

```

```bash

```

## 🎮 Regras do jogo

1. Cada partida apresenta 5 perguntas aleatórias.
2. Cada pergunta possui quatro alternativas.
3. O jogador deve escolher entre A, B, C ou D.
4. Cada resposta correta vale 1 ponto.
5. Não existem perguntas repetidas na mesma partida.
6. Ao final, o programa apresenta o desempenho do jogador.
